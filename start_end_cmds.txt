Open a terminal in the RightStaff directory and run:
cd docker
docker-compose up -d
What this does: Starts PostgreSQL, Qdrant, Redis, and MinIO containers in detached mode (background)
Step 2: Verify Docker Containers are Running
docker ps
Expected output: You should see 4 containers running:
rightstaff-postgres (port 5432)
rightstaff-qdrant (ports 6333, 6334)
rightstaff-redis (port 6379)
rightstaff-minio (ports 9000, 9001)
Step 3: Activate Virtual Environment
Navigate back to RightStaff root directory:
cd ..
venv\Scripts\activate
What you'll see: Your terminal prompt will change to show (venv) at the beginning
Step 4: Start FastAPI Backend
cd backend
uvicorn app.main:app --reload --host 127.0.0.1 --port 8000
What this does: Starts the FastAPI development server with auto-reload enabled Expected output:
INFO:     Will watch for changes in these directories: ['C:\\Users\\katha\\...\\RightStaff\\backend']
INFO:     Uvicorn running on http://127.0.0.1:8000 (Press CTRL+C to quit)
INFO:     Started reloader process [...]
INFO:     Started server process [...]
INFO:     Waiting for application startup.
Starting RightStaff AI Backend...
Environment: development
Debug mode: True
Initializing database...
Database tables created successfully
INFO:     Application startup complete.
Step 5: Access Your Application
API Endpoints:
Main API: http://127.0.0.1:8000
API Documentation (Swagger): http://127.0.0.1:8000/docs
Alternative Docs (ReDoc): http://127.0.0.1:8000/redoc
Health Check: http://127.0.0.1:8000/health
Docker Services:
MinIO Console: http://localhost:9001 (login: minioadmin / minioadmin123)
Qdrant Dashboard: http://localhost:6333/dashboard
To Stop the Application
Stop FastAPI Backend
Press CTRL+C in the terminal where uvicorn is running
Deactivate Virtual Environment
deactivate
Stop Docker Containers
cd docker
docker-compose down
To stop and remove all data:
docker-compose down -v
⚠️ This deletes all database data, use only if you want a fresh start
Quick Start (Single Terminal Session)
If you want everything in one go:
# Start Docker services
cd docker
docker-compose up -d
cd ..

# Start backend
venv\Scripts\activate
cd backend
uvicorn app.main:app --reload --host 127.0.0.1 --port 8000
